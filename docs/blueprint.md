# **App Name**: Bibliosleuth

## Core Features:

- Book Source Aggregation: Scrape book information from Libby, Hoopla, PDF search, and Amazon (used and new).
- Consolidated Book View: Display consolidated results with availability and pricing.
- AI-Powered Recommendations: Use an AI tool to suggest similar titles/authors based on user searches or previously viewed books.
- Watchlist Functionality: Allow users to save favorite books or authors for quick access and notifications.
- Responsive Design: Responsive web design for optimal viewing on different devices (desktop, tablet, mobile).

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to evoke a sense of knowledge and sophistication, reflecting the literary theme.
- Background color: Soft lavender (#E6E6FA), a light tint of indigo, creating a calm, unobtrusive backdrop.
- Accent color: Warm purple (#800080), analogous to indigo, used for interactive elements to add vibrancy and guide user actions.
- Body and headline font: 'Literata', a transitional serif, bringing a literary, vintage feel suitable for a reading app.
- Simple, clean icons representing book formats (audiobook, eBook, print) and sources (Libby, Amazon, etc.).
- Clean and intuitive layout with a focus on readability and easy navigation.

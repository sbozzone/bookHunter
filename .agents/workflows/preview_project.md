# Preview Project Workflow

This workflow details the steps to start the local development server and preview the web application.

## Steps

1. **Start Development Server**
   Run the following command to start the Next.js development server:
   ```bash
   npm run dev
   ```
   *Note: If port 3000 is occupied, it will automatically bind to an alternative port (e.g., 3001).*

2. **Open Preview URL**
   Open the displayed URL in your browser (typically `http://localhost:3000` or `http://localhost:3001`).
